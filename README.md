# 🅰️ React Font Size Changer

Simple React app that lets the user increase or decrease text size dynamically using **useState** and inline styles.

## 🧠 Concepts
- useState hook
- Inline styling in React
- Event handling (`onClick`)

## ⚙️ Features
- Increase and decrease font size
- Real-time visual feedback
- Clean UI with styled buttons
